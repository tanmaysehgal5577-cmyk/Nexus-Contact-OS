# Contact Manager CLI

A professional, menu-driven Command Line Interface (CLI) application implementing complete **CRUD (Create, Read, Update, Delete)** operations with persistent SQLite storage, input validation, data export/import, ANSI styling, and robust exception handling.

---

## Quick Start

Run directly from this directory:
```bash
python main.py
```
Or double-click:
```cmd
run.bat
```

To run tests:
```bash
python -m unittest discover -s cli-crud-app/tests -v
```

See [cli-crud-app/README.md](cli-crud-app/README.md) for complete architecture details and documentation.
